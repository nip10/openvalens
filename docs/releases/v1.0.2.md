Smaller-phone fixes in the app, a daily email digest for reminders, and a
health check for uptime monitors.

## Highlights

- **The meal diary on smaller phones.** Meals come first, and your usual foods
  sit above each meal as one-tap pills. Targets and settings links move below
  the meals. On an iPhone SE, or with large text, the date row and the tab bar
  no longer cut off.
- **Add food fits a small screen.** While you search, the Save button stays
  hidden until you pick a food, so it no longer covers the first result.
- **The app opens straight on the tabs** when you are signed in, without the
  welcome screen in between.
- **Reminders by email arrive as one daily digest** for members who get
  reminders by email only, with new email templates.
- **`GET /api/health`** for uptime monitors that can only send `GET` or
  `HEAD`: 200 when the database answers, 503 when it doesn't.
- The web app's script policy no longer allows inline scripts, and the API
  reference page loads a pinned version of its viewer.

OpenValens is a personal record-keeping and general-wellness app. It is not a
medical device and does not give medical advice.

## Self-hosting: upgrade notes

- Upgrade: `git fetch --tags && git checkout v1.0.2 && deploy/setup.sh upgrade`
  ([Upgrading](https://github.com/nip10/openvalens/blob/v1.0.2/docs/self-hosting/upgrading.md)).
- Migrations: one, additive: the `daily_reminder_email_digest` table. The
  upgrade takes a pre-migrate backup first. Stop the old cron worker before
  starting the new one, so the two versions don't send reminders at the same
  time ([Configuration](https://github.com/nip10/openvalens/blob/v1.0.2/docs/self-hosting/configuration.md)).
- New or changed settings: none required. Optional: the web image takes the
  build arguments `SENTRY_AUTH_TOKEN`, `SENTRY_ORG` and `SENTRY_PROJECT` to
  upload hidden source maps; never put the token in `deploy/.env`.
- Breaking changes and manual steps: none.
- Mobile app: server API version 1. The store app 1.0.2 works with servers
  from 0.9.0 on.

## Mobile app
