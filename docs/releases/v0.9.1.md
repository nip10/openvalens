A beta update before 1.0. The store apps go to TestFlight and Google Play
internal testing only.

## Highlights

- **One health-data consent.** The separate birth-year and sex consent
  checkboxes are gone. The health-data consent asked at sign-up now covers the
  profile answers too, so birth year and sex work as soon as you add them (and
  you have confirmed you are 18 or older). Clearing an answer in Settings still
  removes it.
- **Clearer sign-in.** Opening a sign-in link for an email that has no account
  now says so and points to sign-up, instead of "invalid or expired". The
  sign-in form itself still never reveals which emails have accounts.
- **Android push notifications** (Firebase Cloud Messaging) in the store app.
- **Store review sign-in:** an operator-configured review account can sign in
  with a fixed code, for App Store and Google Play review. Off unless both
  settings are set.
- **Analytics settings** are hidden when the server has analytics off, unless
  you had sharing on.
- Timeline labels are translated and show readable source names; layout fixes
  on Android and iOS.

OpenValens is a personal record-keeping and general-wellness app. It is not a
medical device and does not give medical advice.

## Self-hosting: upgrade notes

- Upgrade: `git fetch --tags && git checkout v0.9.1 && deploy/setup.sh upgrade`
  ([Upgrading](https://github.com/nip10/openvalens/blob/v0.9.1/docs/self-hosting/upgrading.md)).
- Migrations: `20261102120000_drop_wellness_profile_consent` drops the
  `wellness_profile_consent` table (purpose names and timestamps only; stored
  birth years and sexes are kept). The upgrade takes a pre-migrate backup
  first; rolling back to v0.9.0 needs that backup.
- New or changed settings: `REVIEW_ACCOUNT_EMAIL` and `REVIEW_ACCOUNT_CODE`
  (optional, both empty by default; see
  [store review account](https://github.com/nip10/openvalens/blob/v0.9.1/docs/store-review-account.md)).
  Nothing to do unless you publish your own store build.
- Breaking changes and manual steps: none.
- Mobile app: server API version 1. The store app 0.9.1 works with servers
  from 0.9.0 on, and the 0.9.0 app keeps working with a 0.9.1 server.
