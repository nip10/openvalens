The first tagged release of OpenValens: a beta before 1.0, to prove the release
pipeline end to end. The store apps go to TestFlight and Google Play internal
testing only. Version 1.0.0 comes with the public store launch.

## Highlights

- **Your health record in one place:** a dashboard of today's sleep, steps,
  heart rate and weight; labs, body and vitals, workouts and activity, a meal
  diary backed by public food catalogs, sleep, supplements and a timeline.
- **Apple Health and Health Connect sync** in the mobile app, and wearable
  vendor connections that an operator can turn on.
- **Export and delete:** download your record (JSON, CSV or PDF), or delete
  your account and everything you own.
- **Workspaces and sharing** with owner, admin, collaborator and viewer roles.
- **Optional AI assistant,** off by default; it needs both the operator and
  you to turn it on. It is not medical advice.
- **One mobile app for Cloud and self-hosted servers:** on first launch the app
  asks for OpenValens Cloud or the address of your own server, and checks that
  the server speaks an API version it supports.

OpenValens is a personal record-keeping and general-wellness app. It is not a
medical device and does not give medical advice.

## Self-hosting: upgrade notes

- Install or upgrade from the tag:
  `git fetch --tags && git checkout v0.9.0 && deploy/setup.sh upgrade`
  ([Install](https://github.com/nip10/openvalens/blob/v0.9.0/docs/self-hosting/install.md),
  [Upgrading](https://github.com/nip10/openvalens/blob/v0.9.0/docs/self-hosting/upgrading.md)).
  An install that followed `main` before this release upgrades the same way.
- Migrations: every tracked migration up to this tag; `upgrade` applies the
  pending ones after its encrypted pre-migrate backup.
- New or changed settings: none beyond what `upgrade` adds with defaults; it
  prints the names of any keys it added to `deploy/.env`.
- Breaking changes and manual steps: none for an install from `main`. If the
  upgrade creates the backup key, copy it off the server
  ([The backup key](https://github.com/nip10/openvalens/blob/v0.9.0/docs/self-hosting/backup.md#the-backup-key)).
- Mobile app: server API version 1. The store app 0.9.0 works with servers
  from 0.9.0 on (API version 1).
