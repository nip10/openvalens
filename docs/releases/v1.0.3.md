A fix for the mobile app. Nothing changes on the server.

## Highlights

- **Sign out and Delete account open the sign-in screen.** Since 1.0.2 the
  app opens straight on the tabs, and after signing out or deleting the
  account it stayed on them, signed out, until it was restarted. Signing in
  again in the same session also showed "Could not load" errors until a
  restart; screens now load again after sign-in.

OpenValens is a personal record-keeping and general-wellness app. It is not a
medical device and does not give medical advice.

## Self-hosting: upgrade notes

- Upgrade: `git fetch --tags && git checkout v1.0.3 && deploy/setup.sh upgrade`
  ([Upgrading](https://github.com/nip10/openvalens/blob/v1.0.3/docs/self-hosting/upgrading.md)).
  Optional: the server is the same as in v1.0.2.
- Migrations: none.
- New or changed settings: none.
- Breaking changes and manual steps: none.
- Mobile app: server API version 1. The store app 1.0.3 works with servers
  from 0.9.0 on.

## Mobile app

- iOS and Android 1.0.3 (build numbers from EAS). Native change: no
  (JavaScript only).

This release is cut from a release branch (v1.0.2 plus the fix), not from
`main`: `main` already moves the server API to version 2 for the next feature
release.
