A fix for the iOS store build. Nothing changes on the server or on Android.

## Highlights

- **iOS: the App Store build uploads again.** App Store Connect rejected every
  iOS build so far (ITMS-90683) because the app had no Apple Health write
  text. OpenValens still only reads from Apple Health; the text now says so.

OpenValens is a personal record-keeping and general-wellness app. It is not a
medical device and does not give medical advice.

## Self-hosting: upgrade notes

- Upgrade: `git fetch --tags && git checkout v1.0.1 && deploy/setup.sh upgrade`
  ([Upgrading](https://github.com/nip10/openvalens/blob/v1.0.1/docs/self-hosting/upgrading.md)).
  Optional: the server is the same as in v1.0.0.
- Migrations: none.
- New or changed settings: none.
- Breaking changes and manual steps: none.
- Mobile app: server API version 1. The store app 1.0.1 works with servers
  from 0.9.0 on.

## Mobile app

- iOS 1.0.1 (build number from EAS). Native change: yes (Info.plist). Android
  stays at 1.0.0.
