The first stable release of OpenValens, and the public launch of the mobile
app on the App Store and Google Play. It has the same features as v0.9.1.

## Highlights

- **The store apps are public.** OpenValens for iPhone and Android, for
  OpenValens Cloud or your own server.
- No feature changes since v0.9.1: one health-data consent, clearer sign-in,
  Android push notifications and the store review sign-in are all there
  ([v0.9.1 notes](https://github.com/nip10/openvalens/blob/v1.0.0/docs/releases/v0.9.1.md)).

OpenValens is a personal record-keeping and general-wellness app. It is not a
medical device and does not give medical advice.

## Self-hosting: upgrade notes

- Upgrade: `git fetch --tags && git checkout v1.0.0 && deploy/setup.sh upgrade`
  ([Upgrading](https://github.com/nip10/openvalens/blob/v1.0.0/docs/self-hosting/upgrading.md)).
- Migrations: none since v0.9.1. Coming from v0.9.0, the v0.9.1 migration runs
  (see its notes); the upgrade takes a pre-migrate backup first.
- New or changed settings: none.
- Breaking changes and manual steps: none.
- Mobile app: server API version 1. The store app 1.0.0 works with servers
  from 0.9.0 on.

## Mobile app

- iOS and Android 1.0.0 (build numbers from EAS). Native change: no.
