Open-source, private health record.
Your data stays on your server.

OpenValens keeps your labs, body measurements, vitals, workouts, nutrition and sleep in one record that you host yourself. Record, organize, visualize and export it — on a server you control, with no account at anyone else's service.

“Open” means open source (AGPL-3.0). It never means your records are public: an instance has no public sign-up, and every workspace is invite-only.

What it does in 0.1.0

  • Labs

    Enter lab results and keep each marker's readings together in one place.

  • Body and vitals

    Weight, body measurements and vitals, with your own history over time.

  • Workouts and activity

    Log sessions with an effort rating and see your weekly active minutes next to the WHO adult range.

  • Meal diary

    Log meals from imported public food catalogs (USDA FoodData Central, Open Food Facts) or your own foods. Daily totals show which entries had a value.

  • Sleep, supplements, timeline

    Record sleep and supplements and see everything on one timeline.

  • Export and delete

    Download your record (JSON, CSV or PDF) to take to a professional, or delete your account and everything you own.

  • Workspaces and sharing

    Share a workspace with people you invite, as owner, admin, collaborator or viewer.

  • Optional AI assistant

    Off by default. When an operator turns it on (Anthropic or any OpenAI-compatible endpoint, including a local model) and you consent, it can summarise your own records. It is not medical advice and can be wrong.

What it does not do (yet)

  • Backups are not finished. 0.1.0 takes a plain, unencrypted pg_dump before each migration and nothing else. Encrypted, scheduled, off-host backups and a tested restore are still to come. Read the backup guide before you store real records.
  • No hosted service. You run your own instance; there is no sign-up here.
  • No published images. The install builds the containers from the source you check out.
  • No store build of the mobile app. To use it with your instance you build it yourself.
  • No direct wearable-vendor connections such as Oura or Whoop yet.

Where your data goes

Your records live in the Postgres database of your instance, which has no published port and no route to the internet. The app has no analytics and no telemetry.

An instance only talks to outside services that you configure:

  • Email (Resend) delivers sign-in codes, invitations and, only if you opt in, insight notifications. It receives the recipient address and those messages.
  • Let's Encrypt issues the HTTPS certificate for your domain.
  • Off unless you turn them on: an AI provider, Open Food Facts barcode lookup (sends only the product code), S3-compatible file storage, Expo push notifications and one single sign-on provider.

This page follows the same rule: it is plain HTML and CSS served from one origin. No scripts, no web fonts, no trackers, no requests to anyone else.

Install with Docker Compose

One supported install: a pinned Docker Compose stack with Caddy for HTTPS, driven by an interactive setup script that generates every secret on your host. You need a Linux host with Docker Engine, the Compose v2 plugin and git, a domain pointing at it, and a Resend API key for sign-in email. 

git clone https://github.com/nip10/openvalens.git
cd openvalens
git checkout main            # or a release tag, once one exists
deploy/setup.sh install

Read the script before you run it, and read the install guide first: it covers requirements, the one-time setup token for the first administrator, verifying the install and scheduling the daily jobs. All self-hosting guides are in docs/self-hosting.

Intended purpose

OpenValens is a personal record-keeping and general-wellness app. It helps you store, organise and view your own health-related records (such as lab results you enter or import, body measurements, workouts, nutrition, sleep and wearable data) and track healthy habits. It shows publicly available guidance published by recognised public-health authorities, attributed and unaltered, for your information. OpenValens is not a medical device. It is not intended to diagnose, screen for, prevent, monitor, predict, treat or alleviate any disease or condition, and it does not provide medical advice. Talk to a qualified healthcare professional about your health.
